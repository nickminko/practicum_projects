
# Исследование рынка стартапов

## О проекте

Анализ рынка стартапов и венчурных инвестиций для выявления перспективных направлений финансирования. Исследование основано на исторических данных о компаниях, привлечённых инвестициях и возврате средств.

## Цель проекта

Изучить особенности финансирования стартапов, сравнить инвестиционные инструменты и определить перспективные сегменты рынка.

## Данные

- `cb_investments` — информация о компаниях и привлечённом финансировании.
- `cb_returns` — данные о возврате инвестиций по годам и типам финансирования.

## Инструменты

- **Python** — основной язык программирования для анализа данных.
- **Pandas** — обработка, очистка, группировка и анализ данных.
- **Matplotlib** — построение графиков для визуализации результатов исследования.
- **Seaborn** — визуализация распределений и выявление закономерностей в данных.
- **Jupyter Notebook** — интерактивная среда для написания кода, проведения анализа и представления результатов.

## Этапы исследования

- Предобработка и очистка данных.
- Анализ компаний и сегментация рынка.
- Выявление аномальных значений финансирования.
- Сравнение инвестиционных инструментов.
- Анализ динамики финансирования и возврата инвестиций.
- Формулирование выводов и рекомендаций.

## Результат

Проведён анализ структуры рынка стартапов, особенностей привлечения финансирования и динамики возврата инвестиций. Выявлены различия между инвестиционными инструментами и сегментами рынка, сформулированы рекомендации для дальнейшего изучения инвестиционных возможностей.
