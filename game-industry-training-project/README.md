# Исследование рынка видеоигр

## О проекте

Анализ исторических данных об игровой индустрии для изучения продаж игр, особенностей платформ и оценок пользователей и критиков. Исследование охватывает период с 2000 по 2013 год включительно.

## Данные

Датасет `new_games.csv` содержит информацию об играх, платформах, жанрах, продажах по регионам, оценках пользователей и критиков, а также возрастном рейтинге ESRB.

Исходный датасет содержит 16 956 строк и 11 столбцов.

## Инструменты

- **Python** — язык программирования для анализа данных.
- **Pandas** — обработка, очистка, фильтрация и группировка данных.
- **Matplotlib** — построение графиков и визуализация результатов.
- **Jupyter Notebook** — интерактивная среда для проведения анализа и документирования выводов.

## Этапы исследования

- Загрузка данных и знакомство с датасетом.
- Анализ типов данных и обработка пропусков.
- Поиск и удаление явных и неявных дубликатов.
- Приведение названий столбцов к формату `snake_case`.
- Отбор данных за 2000–2013 годы.
- Категоризация игр по оценкам пользователей и критиков.
- Определение семи ведущих платформ по количеству выпущенных игр.

## Результаты

- Проведена предобработка данных: исправлены типы данных, обработаны пропуски и удалены дубликаты.
- Сформирован срез данных за 2000–2013 годы, включающий 12 772 строки и 13 столбцов.
- Игры разделены на категории по оценкам пользователей и критиков.
- Составлен рейтинг семи платформ по количеству выпущенных игр.
